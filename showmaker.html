SHOWMAKER（Stage & Hall Optimization Workflow for Music, Atmosphere, Kinetics, Enhancement & Reconstruction）は、ライブ録音の近接（スポット）マイクのためのリバーブ・プラグインである。スポットマイクは舞台上方のメインペアよりもはるかにドライに収録される。SHOWMAKERは、スポットマイクがメインペアの音とひとつの空間のように溶け合うよう助ける。そのために、スポットをメインペアへの到達時刻に合わせ、ステレオの広がりがメインペアに従う残響を加える[1]。

そのタイミングと広がりを録音から直接読み取る機能が、SHOWMAKERの中核であるLEARNである。メインペアをサイドチェインで受けて再生中の音を分析し、スポットとメインペアの間の実際の遅延を求めて整列を詰め、メインペアの帯域ごとのステレオの広がりを残響に移す。遅延は信頼度の判定とともに表示され、判定が低い場合は整列を変更しない[1]。

SHOWMAKERはホールの残響を再現するものでも測定するものでもない。加えられるのは人工残響であり、LEARNが録音から読み取るのはタイミングとステレオの広がりのみである。残響の長さと量は利用者が決めるため、結果は必ず耳で確認する必要がある[1]。

インストールと初回起動

現在配布しているインストーラーとプラグインはコード署名されていない。そのため、初回実行時にOSが警告を表示する。

Windows

  1. SHOWMAKER-0.6.1-Windows-Setup.exeを実行する。
  2. 「WindowsによってPCが保護されました」と表示された場合は、詳細情報を押してから実行を押す。
  3. インストーラーの案内に従う。スタンドアロン・アプリは任意である。

インストール先：VST3プラグインC:\Program Files\Common Files\VST3\SHOWMAKER.vst3、スタンドアロン・アプリC:\Program Files\LABO 1557\SHOWMAKER\SHOWMAKER.exe（選択した場合）。アンインストール：設定 › アプリ › SHOWMAKER › アンインストール。

macOS（未署名の警告への対処）

  1. SHOWMAKER-0.6.1-macOS.pkgをダブルクリックする。
  2. macOSが「開発元を検証できません」という警告を表示する。
    • macOS 15（Sequoia）以降：完了を押し、システム設定 › プライバシーとセキュリティを開き、下方のSHOWMAKERのメッセージの横にあるこのまま開くを押してパスワードで確認する。
    • macOS 14以前：.pkgをControlキーを押しながらクリック（右クリック）して開くを選び、もう一度開くを押す。
  3. インストーラーの案内に従う。

インストール先：/Library/Audio/Plug-Ins/VST3/SHOWMAKER.vst3、/Library/Audio/Plug-Ins/Components/SHOWMAKER.component、/Applications/SHOWMAKER.app。DAWがプラグインを「壊れている」と表示する、または読み込まない場合は、ターミナルに次の1行を貼り付け（パスワードを求められる）、DAWを再起動する。

sudo xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/SHOWMAKER.vst3" "/Library/Audio/Plug-Ins/Components/SHOWMAKER.component" "/Applications/SHOWMAKER.app"

アンインストール：上記の3項目を削除する。

初めて使うとき

  1. SHOWMAKERをスポットマイクのトラック（または1つのセクションのスポットをまとめたバス）に挿入する。そのトラックのDAWのパンは中央にしておく。
  2. POSITION：楽器が左右のどこにあるかを設定する。
  3. DISTANCE：楽器（スポットマイク）からメインペアまでの距離（m）。おおよその値でよい。SHOWMAKERは距離 ÷ 343 m/sだけスポットを遅延させ、メインペアと同じ時刻に到達させる。
  4. SHOW：加える空間の量。50 %が出発点である。
  5. DECAY：加える残響の長さ。ホールの残響時間ではない。スポットにはすでにホールの響きの一部が含まれている。
  6. ALIGN ON / OFF：再生しながら切り替えて比較する。違いは、露出していてレベルの大きいスポット（ピアノソロ、独奏者）で最も明瞭である。
  7. LEARN：メインペアをサイドチェインに接続してLEARNを押し、遅延と広がりを録音に合わせる（下記のLEARNの節）。

折りたたまれたMOREパネルには、LF DAMP / HF DAMP（低域・高域の残響の長さ）、WET HPF、ALIGN TRIM（微小な遅延）、SPREAD（ステレオのスポットペアの左右間隔）、WIDTH（帯域ごとの残響の広がり：Default / Learned / Off）、INPUT（ステレオトラックの読み方）がある。

LEARN

LEARNはSHOWMAKERの中核機能であり、スポットとメインペアを同時に聴いて録音の中の実際の関係を読み取る。DISTANCEだけで決めた遅延は巻尺で測った値であるが、LEARNはそれを録音された音から確かめ、詰める[1]。

機能

  • 遅延：再生中の10–60秒を取り込み、2秒の窓ごとにスポットとメインペアの相互相関（GCC-PHAT[4]、400 Hz–6 kHz）を求め、DISTANCEで決めた遅延の±2 msの範囲で最も多くの窓が示す遅延を探す。その差がALIGN TRIMに入る。
  • 広がり：メインペアの左右の相関を帯域ごとに測り、残響のステレオの広がりの目標とする（WIDTH = Learned）。
  • 分析はオーディオ処理とは別のスレッドで行われる。結果はプロジェクトとともに保存され、オートメーションの対象ではない。

サイドチェインの接続

  • REAPER：スポットトラックのROUTEで「Track channels」を4にし、マスターセンドは1-2のみにする。メインペアのトラックのROUTEでスポットトラックへのセンドを追加する（オーディオ1/2 → 3/4、Pre-Fader (Post-FX)、0 dB）。SHOWMAKERのウィンドウのピンコネクタで、ステレオトラックはSpot L/R = 1/2、Main pair L/R = 3/4、モノトラックはSpot = 1、Main pair L = 3、R = 4とする。
  • Logic Pro：SHOWMAKERのウィンドウ右上の「Side Chain」メニューでメインペアのトラックまたはバスを選ぶ。

使用手順

  1. 先にDISTANCEを設定する。
  2. このスポットの楽器が露出している箇所を再生する。
  3. LEARNを押して10–60秒待ち、STOPを押す。
  4. 結果がALIGNの行の下に表示される（例：「Delay 10.63 ms (Weak, 46 %) | Width learned」）。
  5. その後、センドは削除してよい。結果はプロジェクトとともに保存される。

結果の読み方

括弧内の百分率は、分析した窓のうち同じ遅延を示した割合である。

判定基準処理
Reliable50 %以上遅延を適用する。
Weak25–50 %遅延を適用する。ON/OFFで耳で確認する。
Ambiguous2番目の遅延候補の窓数が1番目の半分以上1番目の候補を適用し、「two delay candidates, check ALIGN ON/OFF by ear」という警告を付ける。ON/OFFで耳で確認するか、楽器がより露出している箇所で再度試す。
Unreliable25 %未満「Delay not found (Unreliable) - DISTANCE kept」と表示し、DISTANCEをそのまま保つ。別の箇所で再度試す。

メインペアの左右が事実上同じ（モノのペア）場合、広がりは適用せず既定値を保ち、「Width not applied: main pair is mono」と表示する。箇所によって広がりが大きく異なる場合は「(unstable)」が付く。

SHOWMAKER(Stage & Hall Optimization Workflow for Music, Atmosphere, Kinetics, Enhancement & Reconstruction)는 라이브 녹음의 근접(스폿) 마이크를 위한 리버브 플러그인이다. 스폿 마이크는 무대 위의 메인 페어보다 훨씬 건조하게 녹음된다. SHOWMAKER는 스폿 마이크가 메인 페어의 소리와 한 공간처럼 어우러지도록 돕는다. 이를 위해 스폿을 메인 페어의 도달 시각에 맞추고, 스테레오 넓이가 메인 페어를 따르는 잔향을 더한다[1].

그 타이밍과 넓이를 녹음에서 직접 읽어 오는 기능이 SHOWMAKER의 핵심인 LEARN이다. 메인 페어를 사이드체인으로 받아 재생 중의 소리를 분석하고, 스폿과 메인 페어 사이의 실제 지연을 찾아 정렬을 다듬으며, 메인 페어의 대역별 스테레오 넓이를 잔향에 옮긴다. 지연은 신뢰도 판정과 함께 표시되고, 판정이 낮으면 정렬을 바꾸지 않는다[1].

SHOWMAKER는 홀의 잔향을 재현하거나 측정하지 않는다. 더해지는 것은 인공 잔향이며, LEARN이 녹음에서 읽는 것은 타이밍과 스테레오 넓이뿐이다. 잔향의 길이와 양은 사용자가 정하므로, 결과는 반드시 귀로 확인해야 한다[1].

처음 사용할 때

  1. SHOWMAKER를 스폿 마이크 트랙(또는 한 섹션의 스폿을 모은 버스)에 넣는다. 그 트랙의 DAW 팬은 가운데로 둔다.
  2. POSITION: 악기가 좌우 어디에 있는지 정한다.
  3. DISTANCE: 악기(스폿 마이크)에서 메인 페어까지의 거리(m). 대략적인 값이면 된다. SHOWMAKER는 거리 ÷ 343 m/s만큼 스폿을 지연시켜 메인 페어와 같은 시각에 도달하게 한다.
  4. SHOW: 더할 공간의 양. 50 %가 출발점이다.
  5. DECAY: 더할 잔향의 길이. 홀의 잔향 시간이 아니다. 스폿에는 이미 홀의 울림이 일부 담겨 있다.
  6. ALIGN ON / OFF: 재생하면서 바꿔 가며 비교한다. 차이는 드러나 있고 레벨이 큰 스폿(피아노 솔로, 독주자)에서 가장 뚜렷하다.
  7. LEARN: 메인 페어를 사이드체인으로 연결하고 LEARN을 눌러, 지연과 넓이를 녹음에 맞춘다(아래 LEARN 절).

접힌 MORE 패널에는 LF DAMP / HF DAMP(저역·고역의 잔향 길이), WET HPF, ALIGN TRIM(미세 지연), SPREAD(스테레오 스폿 페어의 좌우 간격), WIDTH(대역별 잔향 넓이: Default / Learned / Off), INPUT(스테레오 트랙을 읽는 방식)이 있다.

LEARN

LEARN은 SHOWMAKER의 핵심 기능으로, 스폿과 메인 페어를 함께 들으며 녹음 안의 실제 관계를 읽어 온다. DISTANCE만으로 정한 지연은 줄자로 잰 값이지만, LEARN은 녹음된 소리에서 그 값을 확인하고 다듬는다[1].

하는 일

  • 지연: 재생 중 10–60초를 캡처해 2초 창마다 스폿과 메인 페어의 상호상관(GCC-PHAT[4], 400 Hz–6 kHz)을 구하고, DISTANCE로 정한 지연의 ±2 ms 안에서 가장 많은 창이 가리키는 지연을 찾는다. 그 차이가 ALIGN TRIM으로 들어간다.
  • 넓이: 메인 페어의 좌우 상관을 대역별로 재어 잔향의 스테레오 넓이 목표로 삼는다(WIDTH = Learned).
  • 분석은 오디오 처리와 분리된 별도 스레드에서 이루어진다. 결과는 프로젝트와 함께 저장되며, 오토메이션 대상이 아니다.

사이드체인 연결

  • REAPER: 스폿 트랙의 ROUTE에서 "Track channels"를 4로 하고 마스터 센드는 1-2만 둔다. 메인 페어 트랙의 ROUTE에서 스폿 트랙으로 센드를 추가한다(오디오 1/2 → 3/4, Pre-Fader (Post-FX), 0 dB). SHOWMAKER 창의 핀 커넥터에서 스테레오 트랙은 Spot L/R = 1/2, Main pair L/R = 3/4로, 모노 트랙은 Spot = 1, Main pair L = 3, R = 4로 둔다.
  • Logic Pro: SHOWMAKER 창 오른쪽 위의 "Side Chain" 메뉴에서 메인 페어 트랙이나 버스를 고른다.

사용 순서

  1. DISTANCE를 먼저 정한다.
  2. 이 스폿의 악기가 드러나는 구간을 재생한다.
  3. LEARN을 누르고 10–60초 동안 둔 뒤 STOP을 누른다.
  4. 결과가 ALIGN 줄 아래에 나타난다(예: "Delay 10.63 ms (Weak, 46 %) | Width learned").
  5. 이후 센드는 지워도 된다. 결과는 프로젝트와 함께 저장된다.

결과 읽기

괄호 안의 퍼센트는 분석한 창 가운데 같은 지연을 가리킨 비율이다.

판정기준처리

SHOWMAKER (Stage & Hall Optimization Workflow for Music, Atmosphere, Kinetics, Enhancement & Reconstruction) is a reverb plug-in for the close (spot) microphones of live recordings. Spot mics are much drier than the main pair above the stage. SHOWMAKER helps spot mics blend with the main pair as if they shared one room. To do this, it aligns each spot with the main pair's arrival time and adds a reverb whose stereo width follows the main pair[1].

At the core of SHOWMAKER is LEARN, which reads that timing and width from the recording itself. With the main pair on the sidechain, it analyses the material while it plays, finds the actual delay between the spot and the main pair to refine the alignment, and carries the main pair's stereo width per band over to the reverb. The delay comes with a confidence verdict, and the alignment is left unchanged when confidence is low[1].

SHOWMAKER does not reproduce or measure the hall's reverb. What it adds is an artificial reverb; LEARN reads only timing and stereo width from the recording. Its length and amount are set by the user, so always check by ear[1].

First use

  1. Insert SHOWMAKER on a spot-mic track (or a bus of the spots of one section). Keep the DAW pan of that track centred.
  2. POSITION: where the instrument sits left to right.
  3. DISTANCE: distance from the instrument (its spot mic) to the main pair, in metres. A rough value is enough. SHOWMAKER delays the spot by distance ÷ 343 m/s so that it arrives with the main pair.
  4. SHOW: the amount of added room. 50 % is the starting point.
  5. DECAY: the length of the added reverb. This is not the hall's reverberation time; the spot already carries part of the hall.
  6. ALIGN ON / OFF: switch while playing to compare. The difference is clearest on exposed, louder spots (solo piano, soloists).
  7. LEARN: connect the main pair to the sidechain and press LEARN to fit the delay and width to the recording (see LEARN below).

The fold-out MORE panel has LF DAMP / HF DAMP (reverb length in the low and high bands), WET HPF, ALIGN TRIM (fine delay), SPREAD (distance between L and R of a stereo spot pair), WIDTH (stereo width of the reverb per band: Default / Learned / Off) and INPUT (how a stereo track is read).

LEARN

LEARN is the core of SHOWMAKER: it listens to the spot and the main pair together and reads their actual relationship from the recording. A delay set with DISTANCE alone is a tape-measure value; LEARN checks it against the recorded sound and refines it[1].

What it does

  • Delay: it captures 10 to 60 seconds while playing, computes the cross-correlation between spot and main pair in 2-second windows (GCC-PHAT[4], 400 Hz–6 kHz), and looks for the delay that most windows agree on within ±2 ms of the DISTANCE delay. The difference goes into ALIGN TRIM.
  • Width: it measures the left–right correlation of the main pair per band and uses it as the target stereo width of the reverb (WIDTH = Learned).
  • The analysis runs on a separate thread, apart from the audio processing. The result is saved with the project and is not automatable.

Sidechain routing

  • REAPER: on the spot track, set ROUTE › "Track channels" to 4 and keep the master send on 1-2 only. On the main pair track, add a send to the spot track (audio 1/2 → 3/4, Pre-Fader (Post-FX), 0 dB). In the pin connector of the SHOWMAKER window, use Spot L/R = 1/2 and Main pair L/R = 3/4 for a stereo track, or Spot = 1, Main pair L = 3, R = 4 for a mono track.
  • Logic Pro: choose the main pair track or bus in the "Side Chain" menu at the top right of the SHOWMAKER window.

Steps

  1. Set DISTANCE first.
  2. Play a passage where this spot's instrument is exposed.
  3. Press LEARN, let it run for 10 to 60 seconds, then press STOP.
  4. The result appears under the ALIGN row, e.g. "Delay 10.63 ms (Weak, 46 %) | Width learned".
  5. The send can be removed afterwards; the result is saved with the project.

Reading the result

The percentage in brackets is the share of analysed windows that point to the same delay.

VerdictCriterionAction
Reliable50 % or moreThe delay is applied.
Weak25–50 %The delay is applied. Check by ear with ON/OFF.
AmbiguousThe second delay candidate has at least half as many windows as the firstThe first candidate is applied, with the warning "two delay candidates, check ALIGN ON/OFF by ear". Compare ON/OFF by ear, or try a passage where the instrument is more exposed.
UnreliableBelow 25 %Shown as "Delay not found (Unreliable) - DISTANCE kept"; DISTANCE is kept. Try another passage.

If the left and right of the main pair are practically identical (a mono pair), the width is not applied and the default is kept; the display reads "Width not applied: main pair is mono". If the width varies a lot between parts of the passage, "(unstable)" is added.
